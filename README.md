# Noopy

**A calm, native Mac browser with a sidebar brain.**

Spaces, favorites, splits and a command bar — on its own Chromium engine, with every Chrome extension along for the ride.

### [Download for Mac](https://github.com/maheshwarmurugesan/noopy-releases/releases/latest)

<sub>macOS 14+, Apple silicon. Signed with a Developer ID; first launch: right-click → Open.</sub>
